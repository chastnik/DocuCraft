# DocuCraft Frontend

## Структура страниц

### 1. `/` (index.html)
Страница входа и регистрации
- Автоматическое определение необходимости создания первого администратора
- Форма входа
- Форма регистрации

### 2. `/dashboard.html`
Главная страница со списком проектов
- Просмотр всех проектов пользователя
- Создание нового проекта
- Редактирование и удаление проектов
- Переход к проекту

### 3. `/project.html?id={project_id}`
Страница проекта со списком документов
- Информация о проекте
- Список документов проекта
- Создание нового документа
- Удаление документов
- Переход к настройкам проекта

### 4. `/document.html?id={document_id}`
Страница просмотра и редактирования документа
- Редактор Markdown с предпросмотром
- Поддержка Mermaid диаграмм
- Автосохранение
- Режим просмотра/редактирования
- Поддержка темной темы

### 5. `/project-settings.html?id={project_id}`
Настройки проекта
- Общие настройки (название, описание, Git репозиторий, режим AI)
- Управление участниками проекта
- Роли: Viewer, Editor, ProjectLead
- Git интеграция (webhook URL)

## Компоненты

### CSS
- `css/common.css` - общие стили, переменные темы, компоненты UI

### JavaScript
- `js/api.js` - API клиент для работы с backend
- `js/theme.js` - управление темами (светлая/темная)

## Особенности

1. **Темная тема**: Автоматическое переключение между светлой и темной темой
2. **Markdown редактор**: Двухпанельный редактор с live preview
3. **Mermaid диаграммы**: Поддержка диаграмм в документации
4. **Автосохранение**: Автоматическое сохранение изменений через 2 секунды после остановки ввода
5. **Ролевая система**: Разные уровни доступа к проектам

## API Endpoints

Все API вызовы идут через `/api/v1/`:
- `/auth/*` - аутентификация
- `/projects/*` - управление проектами
- `/documents/*` - управление документами

## Требования

- Современный браузер с поддержкой ES6+
- Marked.js для рендеринга Markdown
- Mermaid.js для рендеринга диаграмм
