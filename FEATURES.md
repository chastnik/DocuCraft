# DocuCraft - Реализованные функции

## ✅ Основной функционал

### Управление проектами
- ✅ Создание, редактирование, удаление проектов
- ✅ Настройка GitHub репозитория
- ✅ Настройка AI режима (suggest-only / auto-apply)
- ✅ Управление участниками проекта с ролями

### Управление документацией
- ✅ Создание, редактирование, удаление документов
- ✅ Версионирование документов (автоматическое)
- ✅ История изменений с привязкой к git commit hash
- ✅ Markdown поддержка
- ✅ Структурированное представление для визуального редактора (JSONB)

### Аутентификация и авторизация
- ✅ Регистрация и вход пользователей
- ✅ JWT токены
- ✅ RBAC (Role-Based Access Control):
  - Viewer - только чтение
  - Editor - редактирование документации
  - ProjectLead - утверждение AI-изменений
  - Admin - полное управление проектом

## ✅ GitHub интеграция

### OAuth
- ✅ GitHub OAuth авторизация
- ✅ Получение и сохранение токенов доступа

### Webhooks
- ✅ Прием GitHub webhooks (push, pull_request, merge)
- ✅ Валидация HMAC подписи
- ✅ Сохранение событий в БД
- ✅ Асинхронная обработка через Celery

### Git анализ
- ✅ Получение информации о коммитах
- ✅ Парсинг git diff
- ✅ Анализ измененных файлов
- ✅ Определение изменений в коде (строки, функции, классы)
- ✅ Поиск затронутых документов

### База данных
- ✅ PostgreSQL с async SQLAlchemy 2.0
- ✅ Миграции через Alembic
- ✅ Версионирование всех сущностей

### Кеширование и задачи
- ✅ Redis для кеширования
- ✅ Celery для асинхронных задач
- ✅ Обработка git событий в фоне

### Безопасность
- ✅ Хеширование паролей (bcrypt)
- ✅ JWT токены
- ✅ Валидация webhook подписей
- ✅ RBAC на уровне сервисов
